# Online Library Management System

## Project Description
Online Library Management System is a full-stack web application developed for CSE 472 Web and Internet Programming course.

The system allows users to register, login, manage books, search books, and perform CRUD operations.

## Features

- User Registration
- Secure Login System
- Add New Books
- Edit Book Information
- Delete Books
- Search Books
- Dashboard
- Database Integration

## Technologies Used

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- PHP

Database:
- MySQL
